# FOXREX — Inside the market (experimental prototype, v2)

Isolated prototype at `/experience/`. It is not linked from production pages, not in the sitemap and not indexed
(`noindex`). Production pages, routes, CMS, the publishing engine and market data are untouched.
Every market value shown is **DEMO / CINEMATIC DATA** (`js/demo-data.js`) and is labelled on screen.

**Current gate:** the owner approved the revised visual plan (`VISUAL-PLAN.md`) with conditions. Only
**01 MARKET NOISE → 02 REX OBSERVES** is implemented. Scenes 03–06 are not built until the owner approves this gate.
The v1 prototype (15 scenes, procedural REX) remains in git history at `54dd0fe`.

## Principles

- **The market is the protagonist.** The same market objects exist from the beginning to the end:
  noise → attention (→ structure → reasoning → clarity → product in later gates).
- **REX is the established Higgsfield REX-MASTER character** (black FOXREX jacket with teal accents from R-03 onward).
  It is never generated or drawn by code. Three.js supports the artwork with depth, light, focus and camera;
  it does not invent the artwork. If REX assets are missing, no REX is drawn. There is no procedural fallback.

## REX key pipeline

The pipeline is chosen per shot **by visual evidence**, not theory:

- `luma`: footage on pure black, with alpha derived from brightness. This is the simplest option, but it damages dark fur,
  the black jacket and shadow detail. A synthetic test card confirmed that a near-black opaque band turns transparent.
- `alpha`: VP9 WebM with a real alpha channel (Chrome, Edge, Firefox). The matte comes from Higgsfield background removal or another masking step.
- `packed`: an ordinary video with colour on top and a greyscale matte below. It plays in every browser, including H.264/HEVC.

Review any shot with `?review=1&key=luma|alpha|packed`.

## Local REX asset handoff

Higgsfield media is downloaded on the owner's machine (the build environment cannot reach the Higgsfield CDN).

1. Download the full-resolution results from Higgsfield into `experience/assets/rex/inbox/`. Keep the Higgsfield
   file name (`hf_…_<job-id>.png`): the job id identifies the shot via `assets/rex/higgsfield-generations.json`.
   Other names: `R-01_<anything>.png|mp4`, or map them in `inbox/manifest.json`.
2. `powershell -ExecutionPolicy Bypass -File experience\ingest-rex.ps1` (macOS/Linux: `./experience/ingest-rex.sh`).
   It identifies each file, validates dimensions / aspect / codec / alpha / black surround, computes SHA-256, writes a
   web-ready candidate (poster, preview, candidate manifest) to `processed/<shot>/<variant>/`, and opens the review.
3. `http://localhost:5180/experience/rex-review/` shows each candidate: A original · B Market Noise composite ·
   C dark exposure · D normal exposure · E close crop · F simulated desktop · G simulated mobile, with
   APPROVE / REJECT / NEXT VARIANT. Decisions are local metadata (`assets/rex/review-decisions.json`).
   R-02 and later stay locked until R-01 is approved.
4. Run the ingest again: the approved variant is copied to `approved/<shot>/` and `rex-assets.json` is rewritten,
   so `/experience/` composites it.

`inbox/`, `processed/`, `approved/`, `rex-assets.json` and `review-decisions.json` are gitignored. Nothing is uploaded,
published or committed automatically; promoting an approved asset into git is a separate owner decision.
Requires Python 3; ffmpeg is optional for stills and needed to verify and encode video (`winget install Gyan.FFmpeg`).

## Owner review

```
./review-local.sh          # macOS / Linux
./review-local.ps1         # Windows PowerShell
```

These open `http://localhost:5180/experience/?review=1`. Keys: `1`–`5` jump to the moments listed above, `P` plays to the end,
`←/→` fine-scrub, `H` hides the panel. The panel shows REX asset status, the key pipeline, the renderer (hardware
or software) and live frame times, and it can run a 40 s journey benchmark and copy a report.
`?adapt=0` freezes quality for screenshots. Review-only framing (used by `rex-review/`): `embed=1`, `p=<0..1>`, `exp=<x>`, `zoom=<x>`, `focusrex=1`, `chrome=0`, `dpr=<x>`. `?motion=reduced` shows still poster frames and follows scroll exactly.

## Performance

Target on the owner's GTX 1660 SUPER-class hardware at 2560×1440: 60 fps, with a 45 fps floor. Resolution adapts to
measured frame time relative to the display refresh, with hysteresis. Only visible REX media decode, and only one shot plays at a time.
The environment reflection renders at 384×216 every second frame while REX is on screen. Headless verification in this
repository runs on SwiftShader (a software rasteriser), so absolute numbers come from the owner's machine.
