# FOXREX Website — Content Audit

**Status:** planning document, 2026-10-04. Nothing here changes the production website.
**Scope:** the public website at `foxrex.co`, as built from the `main` branch (GitHub Pages, `CNAME` = `foxrex.co`), plus
capabilities that exist only in open pull requests. The live site could not be fetched from the audit environment
(outbound access to `foxrex.co` is blocked there), so this audit reads the deployed source on `main` (commit `2bf61c6`).
That source is the exact HTML that GitHub Pages serves.

Labels used below: **MAIN** = deployed on `main`; **PR #6** = built and tested but not merged; **PR #7** = experimental
draft, not part of the website; **ABSENT** = does not exist in this repository.

---

## 2. Arabic edition

- **Coverage:** all 12 pages exist at `/ar/…`, generated from the same build with `<html lang="ar" dir="rtl">`, their
  own canonical URL, hreflang and Open Graph image (`og-image-ar.png`).
- **Composed for Arabic, not toggled:** it uses `styles/ar.css` and the `--ar-*` tokens. The canonical typography is in
  `docs/ARABIC-BRAND-TYPOGRAPHY.md`: **IBM Plex Sans Arabic** for Arabic script and **Inter** for Latin, digits,
  symbols and prices. Latin and number runs are isolated in `<bdi class="lt" dir="ltr">`.
- **Parity:** structure and copy are 1:1 with English. The lessons are real Arabic editorial writing, not machine
  output.
- **Gap:** no Arabic-first content exists beyond the translated page copy. Nothing yet takes advantage of the Arabic
  audience (for example Gulf trading hours or Arabic-language central-bank coverage).

## 4. Content types

**Public feed** (`data/content.schema.json`, schema v2): 8 entry shapes.

| Feed type | Section | Notes |
|---|---|---|
| `MORNING_BRIEF`, `US_OPEN`, `MARKET_RECAP` | `desk` | slot `brief` / `open` / `recap` |
| `EVENT` | `desk` | slot `event`; requires sources and importance; optional `affectedMarkets` and `eventTime` |
| `GOLD_FOCUS` | `gold` | XAUUSD only; bias, marketState, keySupport[], keyResistance[], importantLevel, bull/bear scenarios, invalidation, optional price + priceSource + priceTime |
| `ANALYSIS` | `analysis` | symbol, category (technical/macro/gold/fx/indices/crypto), bias, timeframe, keyLevels[] (strings), scenarios, invalidation |
| `NEWS` | `news` | category, importance, sources (≥1), affectedMarkets, eventTime |
| `LEARN`, `REX_EXPLAINS`, `REX_NOTE`, `ASK_REX` | `learn` | body required |
| `SIGNAL` | `signals` | BUY/SELL, entry, stopLoss, targets[1–5], riskMessage, analysisContext, validity |
| `SIGNAL_RESULT` | `signals` | signalId, entry, exit, outcome (TARGET_HIT, STOPPED_OUT, BREAKEVEN, CLOSED_MANUALLY, EXPIRED), closedAt, resultNotes |

**Common fields:** id, language (en/ar), translationGroupId, section, slot, slug, title, summary, body, symbol, market,
category, bias, tags, image, sources[{name, url, publishedAt, retrievedAt}], riskDisclosure, seo{title, description},
publishedAt, updatedAt, publishVersion.

**Feed rules:** plain text only (no HTML), prices require a source and a time, news and events require sources, and signals
require a stop-loss and a risk message. These rules are enforced by `studio/cms-model.js` (`feedIntegrity()`) and by the schema.

## 5. `data/content.json`

```json
{ "schemaVersion": 2, "updated": null, "publication": null, "items": [] }
```

**The feed is empty.** Every editorial component on the site therefore shows its empty state. The file is one
document capped at 500 items, so it cannot serve as a long-term archive.

## 6. Studio (operator console, `/studio/`)

- **Lifecycle (MAIN):** IDEA → DRAFT → REVIEW → APPROVED → SCHEDULED → PUBLISHED → ARCHIVED. Approval never survives an
  edit. Only the publishing engine performs PUBLISH and UNPUBLISH.
- **Content types (MAIN, `studio/cms-model.js`):** the 13 website types listed in §4. There are also 4 social-only types
  (`REEL`, `STORY`, `CAROUSEL`, `CAMPAIGN`) that never map to the website.
- **Destination map (MAIN):** each type lists its pages (home / gold / analysis / news / learn / signals). There are no
  per-item URLs.
- **Editorial timezone:** Europe/Istanbul. Each record carries EN and AR versions linked by `translationGroupId`. A
  protected-token check stops symbols, prices and times from being changed in translation.
- **Publishing engine (MAIN, PR #5 merged):** the worker writes `data/content.json` from approved records and commits it.
- **Commissioning, preflight, scheduler, audit journal, backups and rollback (PR #6):** built, and run end to end only
  in dry-run mode. `REAL_PUBLICATION=NOT_STARTED`.
- **Creative Studio (MAIN):** social asset production with the Higgsfield provider (paid generation gated by approval)
  and a local LLM. Separate from the editorial CMS.

- **Automated technical analysis, decision system, risk engine, ML:** ABSENT from this repository. Any FOXREX trading

## 9. Signal capabilities

- **Signal and result types with integrity rules (MAIN):** a stop-loss is mandatory and outcomes include losses.
- **Delivery:** Telegram (`@fooxrex`), posted manually. The website lists only signals published through Studio, and none
  are published.
- **Performance and win-rate publication:** deliberately ABSENT ("until independently verified"). This is correct.
- **Automated signal generation, live status tracking (entry hit, stop moved, target hit) and an audit trail of

## 11. About / Contact / Legal

- **About:** strong, honest principles ("No fake data", "Risk first", "People review AI", "Education, not advice").
  There is no team, location, company identity or methodology detail.
- **Contact:** social handles only. There is no email address or business contact, and WhatsApp is "coming soon".
- **Privacy / Terms / Risk Disclosure:** present in EN and AR, last updated 30 September 2026. They are short.
  - They name no legal entity or jurisdiction.
  - There is no editorial-independence or conflict-of-interest statement, which matters for a signals product.
  - Neither covers affiliate or broker relationships, nor any regulatory status statement.

## 13. What is genuinely good and should be kept

- **The honesty rules:** no fabricated prices or performance, explicit unavailable states, a stop-loss before entry,
  losses recorded, people review AI. This is the brand's strongest asset.
- **The editorial rhythm** (09:00 / 11:00 / 14:00 / 15:30 / 19:00 / 22:30 Istanbul) and the Daily Desk concept.
- **The bilingual architecture:** real `/ar/` URLs, the Arabic typography system, protected tokens in translation.
- **One editorial model shared by Studio and the publisher** (`cms-model.js`), with a strict lifecycle and schema.
- **The Market Data Layer design (PR #6):** freshness states, a quality gate, and a site that never talks to a provider.
- **The five REX lessons:** high quality and accurate.
- The Gold Focus structure (bias, levels, two scenarios, invalidation).
