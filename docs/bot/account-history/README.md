## كيف تصدّر
1. MT5 ← تبويب **Geçmiş (History)** ← كبسة يمين ← الفترة.
2. كبسة يمين ← **Rapor** ← HTML (أو Open XML).
3. احفظه بمجلد الحساب. اسم MT5 الافتراضي `ReportHistory-<الحساب>.html` تمام؛ إذا في أكتر من تقرير لنفس الحساب ضيف الفترة: `ReportHistory-<الحساب>_<من>_<لـ>.html`.

لكل حساب جديد: مجلد `<البروكر>-<Demo/Real>-<الرقم>` + سطر بهالجدول.
