# 00-INBOX — الحافظة

هون بتحط أي إشي جديد بدك أشتغل عليه، بدون ترتيب:
- ملفات شموع من MT5 (`XAUUSD_<فريم>_<من>_<لـ>.csv`)
- هيستوري الحسابات (`ReportHistory-<الحساب>.html` أو Open XML)
- تقارير، صور شارتات، ملفات `.set`، ملاحظات

## شو بيصير بعدين
لما تقلي "في ملفات بالحافظة" (أو بشوفها):
1. بفحص كل ملف (نوعه، الفترة، الحساب).
2. بنسخه لمكانه:
   - شموع ← `data\prices\XAUUSD\<الفريم>\`
   - هيستوري ← `data\account-history\<البروكر>-<Demo/Real>-<الحساب>\`
   - تقارير وتحليلات ← `reports\<التاريخ>_<رقم>_<الموضوع>\`
3. بسجل شو انرتب وين بـ `INBOX-LOG.md` هون.
4. **إنت بتمسح الملفات من الحافظة** بعد ما تشوف السجل (أنا ما بقدر أحذف ملفات من جهازك).

## نصيحة للأسماء
خلي اسم MT5 الأصلي زي ما هو. إذا في معلومة زيادة (الإكسبيرت، النسخة، الحساب) حطها بآخر الاسم أو بملف `ملاحظة.txt` جنب الملف.
