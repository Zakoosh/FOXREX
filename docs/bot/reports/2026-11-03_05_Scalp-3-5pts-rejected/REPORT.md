# 05 · سكالبينغ بهدف ثابت 3–5 نقاط — مرفوض

**الهدف المطلوب:** صفقات كتير، هدف 3–5 نقاط، نسبة ربح فوق 60%.
**الاختبار:** 17,280 إعداد (3,456 لكل فريم) · M1 · M5 · M15 · H1 · H4 · هدف وستوب بالنقاط · إعادة دخول.

| الفريم | إعدادات ربحت بكل الفترات ونسبة ربح ≥ 60% |
|---|---|
| M1 | 0 (أحسن واحد: 16 صفقة/يوم، 61–68%، بس معامل ربح 1.01–1.12 وخسر بالمخفية) |
| M5 | 0 |
| M15 | 0 |
| H1 | 0 |
| H4 | 3 (صفقة كل كم يوم، وخسرت بالمخفية) |

**ليش:** السبريد + العمولة ≈ 0.2 نقطة = 5–7% من هدف 3–4 نقاط، والستوب لازم يكون أكبر من الهدف → خسارة وحدة بتمحي 2–3 رابحات.
**البديل اللي انعمل:** أهداف R، و M1 بيسكر 50% على 0.7R (≈ 5 نقاط) → Master.
**الملفات:** `best20_<فريم>.csv` (أفضل 20 حسب أسوأ فترة).
